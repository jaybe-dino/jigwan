# web/ — 터 리포트 UI (프로토타입)

M1 판정 엔진 출력을 그대로 구동하는 **모바일 웹 UI 프로토타입**.
카카오맵 대신 지형 오버레이를 자체 Canvas로 그려 외부 의존성 없이 열린다.

```
web/
├── app.template.html   # 화면·스타일·상호작용 (데이터 자리 __DATA__)
├── render.py           # 엔진 출력 → 템플릿 주입 → dist/index.html
└── dist/index.html     # 생성 결과 (브라우저로 바로 열기)
```

## 생성·실행

```bash
python3 -m web.render          # dist/index.html 생성
# 브라우저로 web/dist/index.html 열기 (또는)
python3 -m http.server -d web/dist 8080   # → http://localhost:8080
```

## 담는 화면 (기획안 §9)

| 화면 | 내용 |
|---|---|
| S1 지도 홈 | 지형 배경 지도, 검색바, 점수 핀, 트렌드 칩 |
| S3 스캔 연출 | 3초 오버레이 애니메이션(현무→청룡백호→수계→도로살→나침반) |
| S4 터 리포트 | 등급 인장, 터 점수, 정확도 게이지, 4축 게이지(재물 메인·오방색), 풍수 오버레이 맵, 근거 레이어, 실거래가 추이, 비보 카드 |
| S6 궁합 | 생년월일 입력 → 궁합%·오행·본명궁·궁합 비보 |
| S9 공유 카드 | 인장+점수+궁합%+한줄평 세로 카드 |

## 데이터 계약

`render.build_data()`가 만드는 JSON이 UI의 유일한 입력이다. 실 서비스(M2)의
Next.js 프론트는 동일 계약을 API로 소비하면 되므로, 이 프로토타입이 곧 프론트 스펙이다.

> 참고: **궁합 산출(만세력)은 데모 예시값**이다(엔진은 M3). 터 점수·근거문·등급은
> 실제 M1 룰북 엔진(`engine.scoring`) 출력이다.
