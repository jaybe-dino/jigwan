# 지관(智官) — AI 풍수지리 서비스 기획안 v1.0

> 작성일: 2026-07-05 · 상태: MVP 개발용 PRD · 개발 환경: Claude Code

---

## 1. 서비스 개요

**한 줄 정의**: 주소를 넣으면 AI가 실제 지형·도로·건물 데이터로 그 터의 풍수지리를 감정해주는 모바일 웹 서비스.

- **서비스명**: 지관 (풍수 전문가를 뜻하는 전통 용어. "AI 지관이 터를 봐드립니다") — 출시 전 KIPRIS 상표검색·도메인 확보 필요
- **포지셔닝**: "직방급 신뢰감 UI × 신점 보는 재미". 부동산 서비스처럼 보이는데 내용은 풍수·사주 — 이 갭이 재미의 원천
- **핵심 전략**: 부동산 의사결정의 마지막 관문인 "이 집으로 결정해도 될까?"라는 **확신의 순간**을 잡는다
- **플랫폼**: 모바일 웹 (설치 없이 링크 클릭 즉시 체험 → 카톡 공유 바이럴 루프에 최적)

### 서비스 3층 구조 (확정)

| 층 | 입력 | 제공 | 역할 |
|---|---|---|---|
| ① 코어 | 주소만 | 터 풍수 감정 리포트 (객관 정보) | 메인 서비스. 주소별 풍수 DB 축적 = 핵심 자산, BM의 기반 |
| ② 바이럴 | +생년월일(시) | 나와 터의 궁합 + 사주 전문 의견 | 공유·확산 엔진. 가볍고 재밌게 |
| ③ 리텐션 | 시기(절기·달·길일) | 시기별 샤머니즘 추천 (비보·길일·방위) | 재방문 루프, 푸시 근거 |

## 2. 타깃

**1차 페르소나: "저점을 노리는 3040 예비 매수자"**

- 실거주 겸 자산 상승 기대. 집값 흐름·저점 매수 타이밍에 관심 높음
- 호갱노노·아실·부동산지인으로 데이터는 이미 다 봤으나 최종 결정의 확신이 없음
- 부동산 카페·맘카페에서 "이 단지 어떻게 보세요?" 묻는 사람
- **핵심 메시지**: "숫자는 다 보셨잖아요. 이제 터를 보세요."

2차 확산 타깃: 2030 자취·이사족 (타로·사주 콘텐츠 소비층, 궁합 공유 바이럴 담당)

### 타깃이 기획에 주는 결정

1. 4개 게이지 중 **재물운을 메인**으로
2. 리포트에 **국토부 실거래가 추이 병기** → 부동산 서비스급 신뢰감 완성
3. **매물 비교(후보 2~3곳)를 MVP에 포함** — 저점 매수 고민자는 항상 후보를 저울질 중
4. 투자 조언 아님 고지 필수 (11장 참조)

## 3. 핵심 사용자 플로우

```
[S1 지도 홈] → 주소 검색 → [S3 스캔 연출 3초] → [S4 터 리포트 (점수·등급)]
                                                      ↓ "이 집과 당신의 궁합은?"
                                          [S5 생년월일 입력] → [S6 궁합 리포트 + 비보 카드]
                                                      ↓
                                          [S9 공유 카드 생성] → 카톡/인스타 → 신규 유입
```

### 입력 5단계 — "정밀 감정 시스템" (확정)

입력을 추가할수록 **감정 정확도 게이지**(62% → 90%)가 차오르는 UI. 추가 입력 자체가 게이미피케이션.

| 단계 | 입력 | 열리는 분석 | 정확도 표기 |
|---|---|---|---|
| Lv.1 | 주소 (카카오 주소 검색) | 터 감정 (룰북 1~7, 10) | ~60% |
| Lv.2 | +생년월일(시) | 궁합·사주 의견. "시간 몰라요" 체크 시 삼주(三柱) 분석 + 안내 | — |
| Lv.3 | +동·호수 (선택) | 좌향·층수·동 배치 해석. **"정밀 감정" 배지** 부여 | ~75% |
| Lv.4 | +집 내부 3문항 | 양택삼요(門·主·灶) 분석 | ~90% |
| Lv.5 | +이사 예정일 / 가족 구성원 | 삼살방·손 없는 날·길일 캘린더 / 가족별 궁합 | — |

**Lv.4 입력 UX (차별화 포인트)**
- 현관 방향: "현관문을 열고 밖을 본 채 폰을 들어주세요" → **폰 나침반 센서(DeviceOrientation API)로 자동 측정**. 의식을 치르는 느낌 = 샤머니즘 감성 + 실측 정확도
- 안방·주방 위치: 집 모양 9칸 그리드에서 탭 2번

### 지도 UX (확정)

1. **홈 = 지도**: 부동산 앱 문법. 검색한 터에 점수 핀
2. **풍수 오버레이**: 분석 결과를 지도 위에 시각화 — 현무(뒷산) 음영, 수계 흐름, 도로살 방향 화살표, 좌향 나침반. 3초 스캔 연출 = 이 오버레이가 그려지는 과정 (연출과 결과물 일원화)
3. **트렌드 히트맵**: "지금 사람들이 기운 보는 동네" — 조회량만 표시. **단지별 점수 공개 금지** (낙인 리스크)

## 4. 분석 엔진 — 풍수 룰북 v1 (확정)

모든 요소는 "입력 → 데이터 → 판정식 → 점수 → 근거 문장 템플릿" 5열 구조.
**원칙: 모든 판정은 숫자가 박힌 근거 문장을 자동 생성한다.** (예: "북서 380m, +42m 능선이 등을 받칩니다 — 현무가 든든한 형국")

### 4.1 터 점수 요소 (주소만으로 계산 — 코어층)

| # | 요소 | 데이터 | 판정 로직 요약 | 배점 |
|---|---|---|---|---|
| 1 | 배산임수 | 국토지리정보원 DEM 5m | 좌향 기준 배면 45° 부채꼴, 200m~1.5km 내 고도차 +20m 이상 능선 = 현무 성립. 고도차·거리로 4단계 | 15 |
| 2 | 사신사 구도 | DEM | 8방위 고도 단면 프로파일 → 좌청룡(동)·우백호(서)·안산(전방) 존재/균형 점수화 | 10 |
| 3 | 환포수/반궁수 | 하천망도 | 하천 곡류의 안쪽(포인트바)=환포(길), 바깥(공격사면)=반궁(흉). 거리 가중 | 10 |
| 4 | 매립지·구하도 | 국토정보플랫폼 옛 지형도 | 과거 하천·논·습지였던 필지 감점 (지반·침수 실익과도 연결) | 5 |
| 5 | 직충살 | 도로명주소 전자지도(도로망 벡터) | T자·막다른 길이 건물 정면 ±15°로 직충 시 성립. 도로 폭·길이 가중 | 8 |
| 6 | 반궁살 | 도로망 벡터 | 반경 100m 내 곡률 도로에서 건물이 곡선 바깥쪽 & 폭 8m 이상 = 성립 | 7 |
| 7 | 고가·철로 인접 | 도로·철도망 | 고가도로/철로와의 거리·높이차 기준 3단계 감점 | 5 |
| 8 | 좌향 24방위 | 건축물대장 + 지적도 | 건물 배치각 → 24방위 좌향 판정. 이기론 해석의 기준값 | 15 |
| 9 | 층수·동 배치 (정밀 감정) | 건축물대장 + 동·호수 입력 | 층수 오행 해석, 단지 내 동 위치의 국세(바람길·조망·중심) | 10 |
| 10 | 주변 POI 길흉 | 카카오 로컬 API | 반경별 혐오시설(장례식장·송전탑·유흥) 감점 / 길 요소(공원·학교·물 방위) 가점 | 15 |

**터 점수 = Σ 배점 (100점 만점)** · 형기 40 / 도로살 20 / 건물 25 / 환경 15

### 4.2 궁합 점수 (+생년월일 — 바이럴층)

| # | 요소 | 로직 |
|---|---|---|
| 11a | 오행 매칭 | 만세력 계산 → 사주 오행 분포·용신 도출 → 터·건물의 오행 성격과 상생상극 (±30) |
| 11b | 동사택/서사택 × 본명궁 | 생년 기반 본명궁 → 집 좌향의 사택 계열과 일치 여부 (±20) |

**궁합% = 50 + 11a + 11b** (0~100 클램프). 터 점수와 독립 → "터는 88점 명당인데 나와 궁합은 41%" 같은 조합이 공유 포인트.

### 4.3 Lv.4~5 확장 요소

| 요소 | 입력 | 로직 |
|---|---|---|
| 양택삼요·가택구성법 | 현관 방위(나침반), 안방·주방 위치(그리드) | 집 자체의 동/서사택 판정 → 본명궁과 문·주·조 배치의 8괘(생기·연년·절명 등) 상생상극 → 구체 비보 처방 ("안방이 절명 방위 — 침대 머리를 동남쪽으로") |
| 삼살방·대장군방 | 현 주소 + 새 주소 + 이사 연도 | 연지 기준 삼살방(예: 2026 오년 → 북방) 계산, 이사 방위각 ±30° 겹치면 경고 + 대안 시기 제시 |
| 손 없는 날·길일 | 이사 예정일 | 음력 9·10일 손 없는 날 + 본인 일주 기준 길일 캘린더 |

### 4.4 점수 분포 설계 (확정)

- 평균 62~68점 대역, 90점 이상은 상위 3% 이내로 캘리브레이션
- 이유: 다 높으면 자랑이 안 되고, 다 낮으면 기분 나빠 공유 안 함. 극단값이 드물어야 "우리집 91점"이 자랑거리가 됨

### 4.5 등급 체계 (확정 — 전통형)

| 등급 | 점수 | 비고 |
|---|---|---|
| 천하명당 | 95+ | 상위 1% |
| 명당 | 85~94 | |
| 길지 | 70~84 | |
| 평지 | 50~69 | |
| 비보지 | <50 | "나쁜 터"가 아니라 **"다스릴 수 있는 터"** — 반드시 비보 처방과 세트로만 표시 (낙인 방지) |

### 4.6 AI(LLM)의 역할

- 룰북 판정 결과(구조화 JSON)를 입력으로 받아 **자연어 리포트·비보 카드 문안을 생성**하는 역할로 한정
- LLM이 점수·판정을 직접 하지 않음 (일관성·신뢰성 확보). 프롬프트에 룰북 근거문 템플릿 제공
- 전문 용어 + 근거 수치 + 한 줄 처방의 3단 문체 유지

## 5. 비보(裨補) 솔루션 — 샤머니즘 라이트

- 처방을 **"오늘의 비보" 카드**로 제공: 구체 행동 + 이유 한 줄 ("현관 왼쪽에 붉은 소품을 두세요. 도로살이 재물 기운을 치고 들어옵니다")
- 부적 느낌의 세로형 카드 디자인 → 저장/공유하고 싶은 오브젝트
- 시기별(절기·달) 갱신 → 리텐션 루프 + 추후 커머스(화분·소품 어필리에이트)의 씨앗

---

## 6. 게이미피케이션 — "당신도 지관이 된다"

**MVP 포함 (라이트)**
- **터 도감**: 감정한 터가 등급별 카드 컬렉션으로 쌓임
- **지관 레벨**: 감정 횟수·공유·비보 실천 체크로 승급 (견습 → 수습 → 지관 → 대지관). 승급 시 심화 해석 해금
- **감정 정확도 게이지**: 입력 추가 유도 (3장 참조)

**v2 백로그**: 절기 한정 부적 카드 컬렉션, 명당 헌터 챌린지, 주간 랭킹, 전국 유명 명당(재벌가 터 등) 탐방 콘텐츠

## 7. 공유·바이럴 설계

### 공유 카드 (제안)

- 포맷 2종: 1080×1920(인스타 스토리) / 1200×630(카톡 OG)
- 구성: 등급 인장(붉은 도장 모티프) + 터 점수 + 궁합% + AI 지관의 한 줄 평 + 서비스 링크(QR)
- **개인정보 보호**: 주소는 행정동 단위까지만 표시 ("서울 마포구 성산동의 어느 터")
- 잘 나와도 공유(자랑), 못 나와도 공유("우리집 43점 실화냐") 되는 카피 톤

### 바이럴 루프 설계

1. 궁합은 사람마다 다름 → "남편 사주로도, 아이 사주로도" 가구당 3~4회 입력
2. 매물 비교 → 이사 고민자는 후보지를 전부 입력
3. 공유 카드 링크 → 받은 사람이 자기 집 입력 → 반복

## 8. 비즈니스 모델 (확정 — 단계형)

> 원칙: 정보 접근권을 팔지 않는다. 파는 것은 ①불안 해소 의식(단건) ②처방→구매 전환 ③의도 데이터.

| Phase | 시점 | 수익원 |
|---|---|---|
| 1 | 출시~ | **전면 무료.** 바이럴·풍수 DB 축적 올인. 비보 커머스 어필리에이트(오늘의집·쿠팡)만 라이트하게 운영비 회수 |
| 2 | 트래픽 검증 후 | **오케이전 단건 결제**: 이사·계약·개업 패키지 리포트 (길일+방위+계약 타이밍+입주 비보) 9,900~19,900원. 시즌 굿즈(신년·이사철 디지털+실물 부적 드롭) |
| 3 | DB·브랜드 확보 후 | **B2B**: 중개·분양 마케팅 리포트("이 단지 명당 동·호"), 프롭테크 API(풍수 점수 위젯), 이사·인테리어·입주청소 제휴 리드 |

- 구독은 BM에서 제외 (단순 정보 구독은 성립하지 않음). 시기별 알림은 무료 리텐션 장치로 활용
- 조회 로그 = 지역별 이사·매수 의도 데이터 → Phase 3의 핵심 자산 (개인정보 비식별 집계 전제)

| S3 | 스캔 연출 | 지도 오버레이 애니메이션 (DEM 음영→수계→도로살 화살표→나침반, 3초) |
| S4 | 터 리포트 | 점수·등급 인장, 4축 게이지(재물 메인), 풍수 오버레이 맵, 근거 레이어(접힘), 실거래가 추이, 정확도 게이지 |
| S5 | 궁합 입력 | 생년월일시, "시간 몰라요" 체크, 달력/시진 피커 |
| S6 | 궁합 리포트 | 궁합%, 오행 매칭 해설, 사주 전문 의견, 비보 카드 |
| S7 | 정밀 감정 | 동·호수 입력, 나침반 측정 UX, 9칸 그리드 |
| S8 | 매물 비교 | 후보 2~3곳 터점수·궁합 나란히, 항목별 우열 |
| S9 | 공유 카드 | 미리보기, 포맷 선택, 카톡/인스타/저장 |
| S10 | 마이 지관 | 터 도감, 지관 레벨, 감정 히스토리 |
| S11 | 이달의 기별 (v2) | 시기별 비보·길일 캘린더, 알림 설정 |

### 근거 레이어 (신뢰 장치, S4 내)

"왜 이 결과?" 탭 → 지형 단면도, 경사·향 수치, 적용 이론(형기론/이기론 어느 조항) 표시. 읽는 사람은 소수여도 존재 자체가 신뢰를 만듦.

## 11. 법적·윤리 장치 (필수)

1. **참고용 고지**: 모든 리포트 하단 고정 — "본 서비스는 전통 풍수지리·명리 이론에 기반한 참고·오락 목적 콘텐츠로, 부동산 투자 권유·자문이 아닙니다"
2. **낙인 방지**: 단지·매물별 점수의 공개 노출 금지 (개인 조회 결과로만 제공). 히트맵은 조회량만. 명예훼손·업무방해 리스크 차단
3. **개인정보**: 생년월일(시)은 개인정보 — 수집 동의, 암호화 저장, 미가입 체험 시 세션 한정 처리. 조회 로그의 상업 활용은 비식별 집계만
4. **위치기반서비스 신고**: 위치정보법상 LBS 사업 신고 대상 여부 법률 검토 (주소 입력 방식이라 해당 없을 가능성 높으나 확인 필요)
5. **감수 크레딧**: 풍수 전공자(대학원 과정 존재)·명리 전문가 감수 확보 시 "감수: OOO" 표기 — 그 자체가 신뢰 장치

## 12. 로드맵·KPI

### MVP 개발 로드맵 (제안)

| 단계 | 내용 |
|---|---|
| M1 | 룰북 v1 상세화(판정식·근거문 템플릿 완성) + 데이터 파이프라인 (DEM·도로망·건축물대장 수집, PostGIS 연산 검증) |
| M2 | 터 리포트 엔진 + 지도 홈 + 스캔 연출 (S1~S4) |
| M3 | 궁합 엔진(만세력) + 공유 카드 + 정밀 감정 (S5~S9) |
| M4 | 터 도감·레벨 + 매물 비교 (S8, S10) → 클로즈드 베타 (부동산 카페·지인 시딩) |
| M5 | 캘리브레이션(점수 분포)·문안 튜닝 → 정식 출시 (이사철 타이밍) |
