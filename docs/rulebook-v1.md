# 지관 풍수 룰북 v1 — 판정식·근거문 명세 (M1)

> 기획안 §4를 구현 가능한 수준으로 상세화한 문서.
> 모든 요소는 **입력 → 데이터 → 판정식 → 점수 → 근거문 템플릿** 5열 구조.
>
> **원칙**: 모든 판정은 숫자가 박힌 근거 문장을 자동 생성한다.

---

## 0. 공통 규약

### 0.1 좌향(坐向) 정의

- `facing_deg`: 건물 정면(向)이 바라보는 방위각. 정북=0°, 정동=90°, 정남=180°, 정서=270°.
- 배면(背, 등)의 방위 = `(facing_deg + 180) mod 360`.
- 좌청룡 = 앉은 자세(배면을 등짐) 기준 **왼쪽 옆구리** = `(facing_deg + 90) mod 360` 방향.
- 우백호 = **오른쪽 옆구리** = `(facing_deg - 90) mod 360` 방향.
- 안산(案山) = 정면 = `facing_deg` 방향.

### 0.2 점수 규약

- 각 요소는 `max_score`(배점) 풀을 가진다. `score ∈ [0, max_score]`.
- **길(吉) 요소**(현무·환포·POI 등)는 성립 시 가점 → `score` 상승.
- **살(煞) 요소**(직충살·반궁살·고가철로·매립지)는 배점을 "감점 여지"로 본다:
  살이 없으면 `score = max_score`(만점), 살이 강할수록 `score` 감소(0까지).
  → 이렇게 하면 Σ`max_score` = 100 이 항상 유지된다.
- **적용 불가**(`applicable = False`): 입력이 없어 판정 못 하는 요소.
  분모(Σmax)에서 제외한다. (예: 주소만 입력 시 R09 층수·동배치)

### 0.3 터 점수 집계

```
터점수 = round( 100 × Σ(적용된 요소의 score) / Σ(적용된 요소의 max_score) )
```

4축 게이지(재물·건강·관계·명예)는 요소별 기여를 축에 매핑해 계산한다(§5).

### 0.4 카테고리·배점 (기획안 §4.1)

| 카테고리 | 요소 | 배점 합 |
|---|---|---|
| 형기(形氣) | R01 배산임수 15, R02 사신사 10, R03 환포반궁 10, R04 매립구하도 5 | **40** |
| 도로살 | R05 직충살 8, R06 반궁살 7, R07 고가철로 5 | **20** |
| 건물 | R08 좌향 15, R09 층수·동배치 10 | **25** |
| 환경 | R10 주변 POI 15 | **15** |
| | | **100** |

## 1. R01 배산임수 (背山臨水) — 배점 15

| 열 | 내용 |
|---|---|
| 입력 | `building.facing_deg`, `building.ground_elevation_m`, `dem[]`(고도 샘플점) |
| 데이터 | 국토지리정보원 DEM 5m |
| 판정식 | 배면 방위 ±22.5°(45° 부채꼴), 반경 200m~1500m 내 DEM 샘플 중 **최대 고도차 Δh** = max(sample.elev − ground_elev). Δh ≥ 20m → 현무 성립. |
| 점수 | 4단계: Δh<10 → 0.20; 10≤Δh<20 → 0.50; 20≤Δh<50 → 0.80; Δh≥50 → 1.00. (×15) |
| 근거문 | `"{방위} {거리}m, +{Δh}m 능선이 등을 받칩니다 — 현무가 {등급어} 형국"` |

- 등급어: 1.00 "든든한", 0.80 "안정된", 0.50 "다소 약한", 0.20 "허(虛)한".
- 능선이 없으면(배면 부채꼴에 +고도 없음): `"배면에 의지할 능선이 없어 바람을 등지지 못하는 형국"`.

## 2. R02 사신사 (四神砂) — 배점 10

| 열 | 내용 |
|---|---|
| 입력 | `building.facing_deg`, `dem[]` |
| 데이터 | DEM |
| 판정식 | 3개 옆구리 방위(좌청룡=facing+90, 우백호=facing−90, 안산=facing)마다 ±22.5° 부채꼴, 200m~1500m 내 최대 Δh. 각 방위별 존재 점수 e = clamp(Δh/30, 0, 1). |
| 점수 | 좌청룡·우백호의 **존재**(가중 0.35씩) + 좌우 **균형**(1 − |e_좌−e_우|, 가중 0.30). (×10) |
| 근거문 | `"좌청룡 {좌Δh}m·우백호 {우Δh}m — {균형평}. 안산은 {안산평}"` |

- 균형평: 균형≥0.8 "청룡백호가 감싸 안는 균형", 0.5~0.8 "한쪽으로 기운 국세", <0.5 "호위가 크게 치우침".
- 안산평: 안산 Δh≥15 "앞을 받쳐주는 안산이 뚜렷", 5~15 "낮은 안산", <5 "안산이 트여 허함".

## 3. R03 환포수/반궁수 (環抱水/反弓水) — 배점 10

| 열 | 내용 |
|---|---|
| 입력 | `building.location`, `streams[]`(하천 중심선 폴리라인) |
| 데이터 | 하천망도(WAMIS) |
| 판정식 | 가장 가까운 하천 세그먼트에 대해: (a) 건물의 하천선 수선거리 d, (b) 곡류 판정 — 건물이 곡선의 **안쪽(포인트바)**=환포, **바깥(공격사면)**=반궁. 부호 s = +1(환포)/−1(반궁). |
| 점수 | 거리가중 w = clamp(1 − d/500, 0, 1). 기본 0.5 + s·0.5·w. (×10) |
| 근거문 | 환포: `"{거리}m 앞 물길이 이 터를 감싸 안습니다 — 재물이 모이는 환포수"` / 반궁: `"{거리}m 물길이 등을 돌린 반궁수 — 기운이 새는 형국(비보 대상)"` |

- 하천 없음: `applicable`이지만 중립(0.5×10=5). 근거문: `"가까운 수계가 없어 물의 길흉은 중립"`.
- 곡률 판정: 세 점(하천선 상 최근접점 P와 상·하류 인접점 A,B)의 외적 부호 × 건물 방향으로 안/바깥 결정.

## 4. R04 매립지·구하도 — 배점 5 (살 성격)

| 열 | 내용 |
|---|---|
| 입력 | `historical.past_types[]` |
| 데이터 | 국토정보플랫폼 옛 지형도 |
| 판정식 | 과거 지목이 {하천·구하도·논·습지·갯벌·매립}에 해당하면 감점. 강도 = 유형별 계수 max. |
| 점수 | 계수: 하천/구하도 1.0, 습지/갯벌 0.9, 논 0.6, 매립 0.8. score = max_score×(1 − 0.8·계수). (×5) |
| 근거문 | `"이 필지는 과거 {유형}이었습니다 — 지반·수맥이 약한 터(현대적으로도 침수·연약지반 유의)"` |

- 해당 없음: 만점. 근거문: `"과거에도 마른 땅 — 지반이 안정된 터"`.

## 5. R05 직충살 (直沖煞) — 배점 8 (살 성격)

| 열 | 내용 |
|---|---|
| 입력 | `building.location`, `building.facing_deg`, `roads[]` |
| 데이터 | 도로명주소 전자지도(도로망 벡터) |
| 판정식 | T자 머리/막다른 길의 축이 건물 정면 방위 ±15°로 정면 충돌하고, 도로 끝점이 건물 정면 방향 반경 120m 내. 강도 = 폭가중 wᵥ=clamp(width/12,0,1) × 근접가중 wₐ=clamp(1−d/120,0,1). |
| 점수 | score = max_score×(1 − 강도). (×8) |
| 근거문 | `"정면 {거리}m에서 폭 {폭}m 도로가 곧게 찔러 들어옵니다 — 직충살(현관 방위 비보 권장)"` |

- 없음: 만점. 근거문: `"정면으로 찔러드는 도로가 없어 직충살 없음"`.

## 6. R06 반궁살 (反弓煞·도로) — 배점 7 (살 성격)

| 열 | 내용 |
|---|---|
| 입력 | `building.location`, `roads[]` |
| 데이터 | 도로망 벡터 |
| 판정식 | 반경 100m 내 곡률 도로에서 건물이 **곡선 바깥쪽**이고 도로폭 ≥ 8m. 강도 = 곡률가중 × 폭가중 × 근접가중. |
| 점수 | score = max_score×(1 − 강도). (×7) |
| 근거문 | `"{거리}m 곡선도로가 활처럼 등을 밀어냅니다 — 도로 반궁살"` |

- 곡선 안쪽이면 오히려 무해(만점). 없음도 만점.

## 7. R07 고가·철로 인접 — 배점 5 (살 성격)

| 열 | 내용 |
|---|---|
| 입력 | `rails_overpasses[]` |
| 데이터 | 도로·철도망 |
| 판정식 | 최근접 고가/철로까지 거리 d와 높이차 |Δz|. 3단계: d<50 → 강; 50≤d<150 → 중; 150≤d<300 → 약; d≥300 → 무해. 높이차 크면 1단계 가중. |

| 근거문 | `"{종류}가 {거리}m·높이차 {Δz}m로 인접 — 기류·소음이 터를 흔드는 형국"` |

## 8. R08 좌향 24방위 — 배점 15

| 열 | 내용 |
|---|---|
| 입력 | `building.facing_deg` |
| 데이터 | 건축물대장 + 지적도(배치각) |
| 판정식 | facing_deg → 24방위(15° 간격) 좌향 판정. 사택(동사택/서사택) 계열 분류. 이기론 해석의 **기준값**. 방위 자체의 길흉은 개인 본명궁 결합(궁합) 전까지 중립 처리하되, 정확한 향일수록(정향 ±3°) 격이 높다고 봄. |
| 점수 | 기본 0.75. 사방위(자/오/묘/유=정N/S/E/W)·사우(건곤간손) 정향 근접도 보정 ±0.15, 애매한 경계각(방위 경계 ±3°)이면 −0.1. (×15) |
| 근거문 | `"건물은 {좌}좌 {향}향({facing}°) — {사택}에 속하는 배치"` |

- 24방위 표: 임자계·축간인·갑묘을·진손사·병오정·미곤신·경유신·술건해 (壬子癸 丑艮寅 甲卯乙 辰巽巳 丙午丁 未坤申 庚酉辛 戌乾亥).
- 동사택: 감(子)·리(午)·진(卯)·손(巽) 계열 / 서사택: 건·곤·간·태 계열. (상세 매핑은 `engine/rulebook/r08_orientation.py`.)

## 9. R09 층수·동 배치 (정밀 감정) — 배점 10

| 열 | 내용 |
|---|---|
| 입력 | `building.floors`, `precision.dong_position`(선택, Lv.3) |
| 데이터 | 건축물대장 + 동·호수 입력 |
| 판정식 | 층수 오행(1·6水, 2·7火, 3·8木, 4·9金, 5·0土) 해석 + 단지 내 동 위치의 국세(중심/외곽, 바람길, 조망). **동·호수 미입력 시 `applicable=False`.** |

| 근거문 | `"{층}층은 오행상 {오행} — {해설}"` (+동 배치 문장) |

> M1에서는 층수 오행까지 구현. 동 배치 국세(바람길/조망)는 Lv.3 데이터가 붙는 M3에서 확장.

## 10. R10 주변 POI 길흉 — 배점 15

| 열 | 내용 |
|---|---|
| 입력 | `building.location`, `pois[]`(카테고리·좌표) |
| 데이터 | 카카오 로컬 API |
| 판정식 | 반경별 가중. 흉(장례식장·송전탑·유흥·쓰레기)·길(공원·학교·도서관·병원·물). 각 POI 기여 = 부호 × 카테고리가중 × 거리감쇠(clamp(1−d/R,0,1)). 합산 → tanh 정규화. |
| 점수 | 0.5 + 0.5·tanh(Σ기여). (×15) |
| 근거문 | 가장 강한 흉/길 요소를 뽑아: `"{거리}m {POI명}이(가) {길흉}으로 작용 — {총평}"` |

- 카테고리 가중·반경 표는 `engine/rulebook/r10_poi.py`.

## 11. 궁합 (바이럴층 — M3 구현, M1 명세만)

터 점수와 **독립**. `궁합% = clamp(50 + 11a + 11b, 0, 100)`.

### 11a 오행 매칭 (±30)

| 입력 | 로직 |
|---|---|
| 생년월일(시) | 만세력 계산 → 사주 오행 분포·용신 도출 → 터·건물의 오행 성격과 상생상극. 용신이 터 오행과 상생 +, 상극 −. |

### 11b 동사택/서사택 × 본명궁 (±20)

| 입력 | 로직 |
|---|---|
| 생년 | 본명궁(구성) 산출 → 집 좌향(R08)의 사택 계열과 일치 여부. 동-동/서-서 일치 +20, 불일치 −20, 부분 ±10. |

> 만세력 엔진은 M3. M1에서는 `engine/models.py`에 `SajuProfile` 자료형과
> `engine/rulebook/compat.py`에 **인터페이스+근거문 템플릿**만 정의한다.

## 13. 점수 분포 캘리브레이션 (기획안 §4.4)

- 목표: 평균 62~68점, 90+ 상위 3% 이내.
- M1은 판정식만 확정. 실제 분포 캘리브레이션은 표본 지역 감정 후 M5.
